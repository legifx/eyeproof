# Field reports

Short reports from real AI coding-agent sessions that used eyeproof: what it caught, what it missed, false
alarms, friction, ratings. They show how the tool holds up outside its own benchmark.

Every report is **anonymized** before it is sent. It never names private projects, people, machines, paths,
URLs, ports, hosts, commits or credentials, and it contains no screenshots. A project is named only when its own
repository is public. Reports are written by the agent at the end of a session and checked by a scanner that
blocks the pull request on any hit.

Use [TEMPLATE.md](TEMPLATE.md) to write one by hand.
